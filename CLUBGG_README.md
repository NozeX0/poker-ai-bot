## 🚀 УСТАНОВКА И ЗАПУСК

### **Шаг 1: Установить зависимости**

```bash
pip install -r requirements-clubgg.txt
```

### **Шаг 2: Установить Tesseract OCR**

**Windows:**
- Скачайте: https://github.com/UB-Mannheim/tesseract/wiki
- Установите по умолчанию
- Перезагрузитесь

**macOS:**
```bash
brew install tesseract
```

**Linux:**
```bash
sudo apt-get install tesseract-ocr
```

### **Шаг 3: Запустить приложение**

**Windows:**
```bash
python clubgg_overlay.py
```
Или просто двойной клик по `run_clubgg.bat`

**macOS/Linux:**
```bash
chmod +x run_clubgg.sh
./run_clubgg.sh
```

## 📱 КАК ИСПОЛЬЗОВАТЬ

### **Пошагово:**

1. **Откройте ClubGG в браузере**
   - Зайдите на https://clubgg.com
   - Откройте любой стол (можно виртуальные деньги)
   - Разместите окно браузера на левой половине экрана

2. **Запустите это приложение**
   ```bash
   python clubgg_overlay.py
   ```

3. **Подождите инициализации**
   - Приложение начнет анализировать экран
   - Первая подсказка может появиться через 2-5 секунд

4. **Видите подсказку!** 🎉
   - На экране появится оверлей с рекомендацией
   - Зелёный = RAISE (максимальный+)
   - Голубой = CHECK (нейтрально)
   - Оранжевый = CALL (среднее+)
   - Красный = FOLD (сливай)

### **Метрики:**

- **Action** → FOLD/CALL/RAISE/CHECK/BET (основное действие)
- **Confidence** → Уверенность 0-100%
- **Equity** → Вероятность выигрыша в %
- **EV** → Математическое ожидание в $
- **Bet Size** → Рекомендуемый размер ставки
- **Reasoning** → Почему это действие
- **Cards** → Распознанные карты
- **Board** → Распознанный борд

## ⚙️ КОНФИГУРАЦИЯ

### **Изменить частоту анализа:**

В `clubgg_overlay.py` найдите:

```python
time.sleep(0.1)  # Анализ 10 раз в секунду
time.sleep(0.033)  # Отрисовка 30 раз в секунду
```

Ставьте меньше значение = быстрее анализ (но больше нагрузка)

### **Изменить позицию оверлея:**

```python
x_pos = self.screen_width - 500  # От правого края
y_pos = 50  # От верхнего края
```

### **Изменить размер оверлея:**

```python
width = 450  # Ширина
height = 350  # Высота
```

## 🐛 TROUBLESHOOTING

### **❌ Ошибка: "Tesseract not found"**

```bash
Решение:
1. Установите Tesseract (см. выше)
2. Перезагрузитесь
3. Убедитесь что установлен в Program Files
```

### **❌ Ошибка: "No cards detected"**

```bash
Решение:
1. Улучшите освещение экрана
2. Увеличьте контрастность
3. Убедитесь что карты полностью видны
4. Проверьте что браузер на полный экран
```

### **❌ Оверлей не видно**

```bash
Решение:
1. Проверьте что Pillow установлен: pip install Pillow
2. Убедитесь что разрешение экрана 1920x1080 или больше
3. Попробуйте переместить окно ClubGG
```

### **❌ Медленный анализ**

```bash
Решение:
1. Уменьшите разрешение экрана
2. Закройте ненужные приложения
3. Увеличьте интервал анализа (time.sleep(0.2))
```

## 💡 СОВЕТЫ

1. **Используйте браузер в полный экран**
   - Картинка четче
   - OCR работает точнее

2. **Не перекрывайте карты**
   - Держите область my_cards открытой
   - Иначе не распознает

3. **Хорошее освещение экрана**
   - Контрастные цвета
   - Четкие границы карт

4. **Калибровка регионов**
   - Если не распознает - отредактируйте _init_regions()
   - Подгоните под размер вашего экрана
