# 🤖 Poker AI Bot - Complete Edition

**Полнофункциональный покер-бот с ИИ анализом. Работает на ПК и мобильных!**

## ⚡ БЫСТРЫЙ СТАРТ (30 секунд)

```bash
# 1. Клонируем
git clone https://github.com/NozeX0/poker-ai-bot.git
cd poker-ai-bot

# 2. Устанавливаем
pip install -r requirements.txt

# 3. Запускаем
python app.py

# 4. Открываем http://localhost:5000
```

**ДА! ВСЕ! Готово! 🎉**

## 📱 НА МОБИЛЬНОМ

Откройте в браузере на телефоне:
```
http://ИП_ВАШЕГО_ПК:5000
```

Например:
```
http://192.168.1.100:5000
```

## 🎮 КАК ИСПОЛЬЗОВАТЬ

1. **Введите ваши карты** (AS KH)
2. **Введите борд** (QD JC 9H) или оставьте пустым
3. **Заполните данные**: банк, ставка, стек
4. **Нажмите АНАЛИЗ** → ИИ выдаст рекомендацию

## 🎓 СТРАТЕГИЯ

**СИЛЬНЫЕ РУКИ (TOP PAIR+):**
- ACTION: RAISE
- Bet: 0.5 - 0.75 pot

**СРЕДНИЕ РУКИ (PAIR, DRAW):**
- ACTION: CALL или CHECK
- Зависит от odds

**СЛАБЫЕ РУКИ:**
- ACTION: FOLD
- Если нет хороших odds
